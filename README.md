# 🌦 Weather App

A responsive weather application built using HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Auto location weather
- Temperature-based background
- Dark mode
- Rain & snow animation
- Rain sound effect
- Wind speed & pressure
- Mobile responsive design

## Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeather API
